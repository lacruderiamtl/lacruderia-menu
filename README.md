# 🌮 La Cruderia — Menú Digital Interactivo

Menú digital web de alta gama diseñado para el restaurante **La Cruderia** (Montréal, QC). Desarrollado con una estética elegante en tonos negro mate y acentos dorados, optimizado tanto para teléfonos móviles (ideal para el enlace en la biografía de Instagram) como para pantallas de escritorio.

## 🚀 Características Principales

- 🌐 **Soporte Trilingüe:** Cambio instantáneo entre Español, Inglés y Francés.
- 📱 **Diseño 100% Responsivo:** Interfaz adaptativa con vista de escritorio multicolumna y barra de pedidos flotante en móviles.
- 🛒 **Calculadora e Interfaz de Pedidos:** Carrito interactivo que calcula el total acumulado en tiempo real.
- 📲 **Integración con WhatsApp:** Envío directo del resumen del pedido al número del restaurante para una atención inmediata.
- 🔍 **Búsqueda y Filtros:** Filtrado rápido por categorías (Entradas, Burritos, Tacos, Caldos, Postres) y buscador por palabras clave.
- 📍 **Información Comercial:** Integración directa de direcciones (Rue Bélanger y St-Hubert), horarios de atención actualizados y redes sociales.

## 🛠️ Tecnologías Utilizadas

- **HTML5** (Estructuración semántica)
- **CSS3** (Variables CSS, Flexbox, CSS Grid y diseño responsivo)
- **JavaScript (ES6+)** (Gestión de estado del carrito, traducciones dinámicas y manipulación del DOM)
