# lacruderia-menu
Menú Digital Interactivo y Elegante para La Cruderia 🇲🇽🇨🇦 Aplicación web trilingüe (ES / EN / FR) optimizada para dispositivos móviles y escritorio. Permite a los clientes explorar el menú, filtrar por categoría, calcular el total de su pedido en tiempo real y enviarlo directamente a través de WhatsApp.
